# 状态接地层·几何解析实测发现（2026-09-24）

> 用真实 Marble 导出资产（world 30687dba…）实测 GLB 解析，检验"从几何反推物体"的可行性。
> 结论直接影响状态接地层的技术路线，必须记录。

## 实测结果

对正式模型 marble-1.1 导出的 collider GLB（2.86 MB）做解析：

| 项 | 数值 |
|---|---|
| 总面数 | 108,049 |
| 顶点数 | 55,742 |
| 整体包围盒 | min [-9.88, -8.36, -15.26] ~ max [15.45, 0.75, 12.07] |
| **连通域分割结果** | **仅 2 个成分**（一个 105,709 面的大块 + 一个 2,025 面的小块） |

## 关键结论

**连通域分割无法恢复物体级包围盒。** 整个场景被烘焙成**一整块合并几何**，而非按物体分块。这意味着：

1. ❌ 原计划的"连通域分割 → 每个物体一个包围盒"路线**不成立**。
2. ⚠️ 这也印证了此前实测：GLB 节点名仅 `world`/`geometry_0`，无任何物体切分或语义标签。
3. ✅ 空间聚类（体素法）可给出几何的空间分布：体素 0.5 时占用 3,181 格、体素 1.0 时 833 格——**可用于描述"哪里有几何、哪里是空的"的空间占用，但无法自动切出"沙发""茶几"这类语义物体**。

## 对状态接地层设计的影响（重要）

状态接地层的三条数据流，重要性排序需调整：

| 数据流 | 可行性 | 结论 |
|---|---|---|
| **caption 文本** | ★★★★★ | 直接可用，含物体类型/材质/空间关系，是**主力** |
| **pano 全景图 + 多模态 LLM** | ★★★★☆ | 通过视觉理解反推物体布局，**成为物体级语义的主要来源** |
| GLB 几何 | ★★☆☆☆ | **只能提供空间占用/整体尺度**，无法单独反推物体级语义 |

**修订后的状态接地层技术路线**：
- 物体级语义（"有哪些物体、是什么"）→ 主要由 **caption + pano 多模态推理** 提供；
- 空间占位与尺度 → 由 **GLB 整体几何 + 体素占用** 提供（用于校验、定位）；
- 两者融合 → 结构化快照。

## 对论文的意义

这一发现**进一步强化**了状态接地层的贡献——因为底层导出物比预想的更"不结构化"（连几何都不是按物体切的），自建接地层的必要性更强。同时也意味着论文中"几何解析（连通域分割）"的表述需要改为"几何空间占用分析 + 视觉语义推理"的融合。**这是一处需要回改论文 §3.2.2 的地方。**
